# Digital Tool Reflection: Codex

For this assignment, I chose **Codex** (an AI coding assistant) as my digital design tool. Instead of planning everything on paper first, I used Codex as a real-time collaborator while building my portfolio website. It helped me organize ideas, generate and revise code, and troubleshoot issues during development.

I used Codex while creating a **Windows XP-style portfolio website**. I asked it for help structuring my files, improving layout behavior, and implementing interface features like desktop icons, pop-up windows, a taskbar, and interactive controls (open, close, minimize, maximize). It was especially helpful for:

- speeding up iteration (I could test ideas quickly),
- debugging JavaScript logic,
- improving HTML/CSS structure and consistency,
- and reducing the time needed to move from concept to working design.

Compared to paper-only workflows, Codex made the design process more interactive and efficient because I could immediately translate ideas into a functional prototype.
