# 🖥️ XP Portfolio

An interactive personal portfolio website inspired by **Windows XP**.  
Instead of a static page, users explore my work through a retro desktop-style 
experience with login flow, draggable windows, and system-like UI behavior.

## 🎯 Purpose

This project showcases my frontend skills in:
- Event-driven UI logic
- Custom window management
- Responsive layout behavior
- Creative interface design with nostalgic styling

## 👤 About This Portfolio

This portfolio is built to feel like a mini operating system experience 
while presenting my background, projects, and achievements in a memorable way.

## ✨ Core Features

- 🔐 XP-style **Login → Welcome → Desktop** flow
- 🪟 App-like windows with **open, drag, minimize, maximize, close**
- 📌 Taskbar integration for managing opened windows
- 🚀 Functional **Start Menu** + **All Programs** flyout
- 🕘 **My Recent Documents** behavior (reopen last closed window)
- 📄 Embedded **Resume PDF** window
- 🧑‍💻 Desktop icons for **About Me, Projects, Contacts, Resume, Accomplishments, Recycle Bin**
- 🌐 External links to project repos and demos
- 📬 Contact section with **Email, GitHub, LinkedIn, Discord**
- ⏰ XP-like system tray details (clock, status area, popup alert)
- 🔌 **Log Off** and **Turn Off Computer** actions with themed shutdown fallback

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
